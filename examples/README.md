# Offline smoke-test image

`sample.png` is a synthetic 640×480 indoor frame (beige wall, gray floor, red
cube) generated by [`gen_sample.py`](gen_sample.py). It is not a photograph.

```bash
python3 examples/gen_sample.py    # regenerate
make smoke                        # stop_judge.py --image examples/sample.png
```

The smoke prompt is `red cube.` (see `SMOKE_SAM_PROMPT` in
[`scripts/pins.env`](../scripts/pins.env)). Visualizations land in
`smoke_output/` (gitignored).

This path does **not** start ROS or a robot. For the live Go2 stack see
[docs/real_robot.md](../docs/real_robot.md).
